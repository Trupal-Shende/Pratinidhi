Pratinidhi (JanSeva) — Autonomous Civic AgentA voice-first, consent-driven telecom agent empowering non-digital natives to navigate Indian government portals without middlemen, dashboards, or hidden fees.📖 The ProblemMillions of Indian citizens—such as elderly pensioners and migrant workers—are excluded from vital government services due to a severe digital divide. Existing solutions focus on building complex web dashboards that require high digital literacy, English proficiency, and smartphone ownership. Consequently, citizens rely on exploitative middlemen, risking data privacy and paying exorbitant fees for free public services.💡 Our Paradigm Shift: The Dual-Interface ArchitecturePratinidhi fundamentally rethinks civic tech. We realized that for this demographic, the UI is not a screen—it is a phone call.This repository features a unique Dual-Screen Interactive Demo designed for hackathon judges to experience both sides of the ecosystem simultaneously:The Citizen Interface (Left Screen): A simulated toll-free keypad phone (1800-JAN-SEVA). Citizens interact purely via spoken Hindi/English and DTMF keypad presses (e.g., "Press 1 to consent"). No smartphone required.The Companion / Kiosk Portal (Right Screen): A secure oversight web dashboard designed for literate family members or village kiosk operators. It provides a real-time immutable audit trail, DigiLocker consent tracking, and portal payload previews.✨ Key Features & Security by DesignSub-Second Multilingual Voice Intake: Powered by Groq's whisper-large-v3, capturing intent natively in regional dialects.Zero-Middleman Guarantee: The agent handles forms, but never asks for passwords or OTPs. Official acknowledgement receipts are sent directly to the citizen's SMS inbox.Granular DTMF Consent: Documents are retrieved from DigiLocker only after explicit, per-document keypad consent. Irreversible actions are hardware-gated.Hardened Security Architecture:Strict multi-tenant isolation preventing IDOR data leaks.Express rate-limiting to prevent upstream AI quota depletion.10MB payload boundaries with strict MIME-type audio whitelisting.🛠 Tech StackLayerTechnologyPurposeFrontend UIReact 19, Vite, Tailwind CSSResponsive, zero-layout-shift UI for the companion portal and interactive phone simulator.Backend APINode.js, Express (TypeScript)Unified single-port architecture serving Vite SPA and secure REST endpoints concurrently.Voice / STTGroq SDK (whisper-large-v3)Ultra-low latency voice-to-text processing for Hindi and English audio buffers.AI / ReasoningGoogle Gemini APIMultimodal document parsing, PRD validation, and intent-to-service classification.Data / StorageTyped In-Memory StoreStrongly typed schema for application lifecycle, document quality flags, and audit logging.🚀 Local Setup Instructions (For Judges)1.
